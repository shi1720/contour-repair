ETNA submission version

This folder contains the manuscript formatted with ETNA's official class,
with line numbers, alphabetical references and figures sized for journal
columns. The original author version remains in the parent directory.
No journal acceptance or publication is implied.

Compile: tectonic main.tex
Regenerate journal figures from the repository root:
  python3 paper/etna/plot_figures.py

The official etna.cls retains its LaTeX Project Public License notice.
The source file suppresses unassigned publication metadata in the submission
copy; it does not assign a volume, year of publication, DOI or acceptance date.
Official formatting guidance: https://etna.ricam.oeaw.ac.at/submissions/
